# Arbor

Arborは、ツリー構造のドキュメントを人間とAIの双方で編集できる、依存ライブラリ不要のシングルHTMLアプリケーションです。

名前の「Arbor」はラテン語で「木」を意味します。知識を幹から枝へ伸ばすように整理し、育てていくことを表しています。

## 特徴

- `index.html` だけで動作
- ノードを親子・兄弟関係で構成するツリー型ドキュメント
- AIを使用しない通常の追加・編集・移動・削除
- OpenRouterおよびLiteLLMによるAI共同編集
- タグと階層外の関連ノード
- キーワード横断検索
- JSON・CSVのインポートと、JSON・CSV・Markdownのエクスポート
- 入出力用JSON Schemaのダウンロード
- IndexedDBによるブラウザ内保存
- デスクトップ／モバイル対応

## 起動方法

外部ライブラリやビルド処理は必要ありません。ローカルHTTPサーバーを起動します。

```bash
python3 -m http.server 8000
```

ブラウザで次のURLを開きます。

```text
http://localhost:8000
```

## ノードの構造

各ノードは以下の情報を持ちます。

- タイトル
- 概要
- 本文
- 親ノード
- 子ノード
- 同じ親を持つ兄弟ノード
- 複数のタグ
- 階層とは独立した関連ノード
- 並び順
- 更新日時

## AIを使用しない編集

AI接続を設定しなくても、すべての基本的な編集機能を利用できます。

### ノードを追加する

- ルートノード：左ペイン上部の「＋」を選択
- 子ノード：親にするノードを選択して「子ノードを追加」を選択

### ノードを編集する

左のツリーでノードを選択し、中央画面のタイトル・概要・本文を直接編集します。変更内容はIndexedDBへ自動保存されます。

### ノードを移動する

左のツリーでノードをドラッグします。ドロップ位置によって動作が変わります。

- 対象ノードの上端：対象の直前へ移動
- 対象ノードの下端：対象の直後へ移動
- 対象ノードの中央：対象の子ノードとして移動

上端／下端へのドロップでは兄弟ノードの順番を変更でき、挿入位置が緑色の線で表示されます。

### ノードを削除する

対象ノードを選択し、中央画面のゴミ箱ボタンを選択します。確認後、対象ノードとその配下にあるすべての子ノードが削除されます。

## タグ

ノードには複数のタグを付与できます。

1. 対象ノードを選択
2. 「＋ タグ」を選択
3. タグ名と色を指定

付与済みタグの「×」を選択すると、そのノードからタグを外せます。

## 関連ノード

親子関係とは別に、任意のノード同士を関連付けられます。

1. 対象ノードを選択
2. 画面下部の「関連を追加」を選択
3. 関連先と「参照」「前提」「補足」などのラベルを指定

関連先を選択すると、そのノードへ移動します。

## キーワード検索

左ペインの検索欄から、以下を横断検索できます。

- タイトル
- 概要
- 本文
- タグ名

検索結果にはタイトル、階層パス、一致箇所の抜粋が表示されます。一覧から結果を選択すると対象ノードへ移動し、折りたたまれている祖先ノードも自動的に展開されます。

`Ctrl + K` または `Command + K` で検索欄へ移動できます。

## AI共同編集

AIは、選択中ノードとツリー全体の概要を参照できます。さらに、文章の作成・更新時にはアプリ内の検索ツールを使い、他のノードのタイトル・概要・本文・タグ・階層・関連性を取得して内容を検討できます。

依頼文に関連するノードは最初に自動検索されます。その後もAI自身が必要に応じて検索語を変えながら、最大3回まで追加検索できます。これにより、既存文書との重複、用語の統一、前提、内容の矛盾を確認してから変更案を作成します。

検索はブラウザ内のIndexedDBから読み込まれたデータに対して行われます。検索結果として選ばれたノードの内容は、文章生成のため選択中ノードと一緒に設定済みのAI APIへ送信されます。

利用例：

- 本文を改善する
- 子ノードを提案して追加する
- ツリー全体の構成をレビューする
- 既存ノードを更新する
- ノードを削除する

AIによる構造変更は即時実行されません。変更案が表示され、ユーザーが「適用」を選択した場合のみ反映されます。

### OpenRouter

右上の設定ボタンから以下を登録します。

- プロバイダー：OpenRouter
- APIキー
- モデル名（例：`openai/gpt-4o-mini`）

リクエスト先：

```text
https://openrouter.ai/api/v1/chat/completions
```

### LiteLLM

右上の設定ボタンから以下を登録します。

- プロバイダー：LiteLLM
- Base URL（例：`https://litellm.example.com/v1`）
- APIキー
- LiteLLM側で定義されたモデル名

Base URLの末尾に `/chat/completions` を追加して、OpenAI互換APIとして呼び出します。Base URL自体が `/chat/completions` で終わる場合は、そのURLをそのまま使用します。

ブラウザからLiteLLMへ直接接続するため、LiteLLMサーバー側で適切なCORS設定が必要です。

## データの書き出し

右上の「書き出す」から選択できます。

### JSON

以下を含む完全なドキュメントデータを出力します。

- ドキュメント情報
- ノード
- タグ
- 関連性
- フォーマットバージョン
- 出力日時

### CSV

1ノードを1行として出力します。主な列は以下のとおりです。

| 列 | 内容 |
| --- | --- |
| `id` | ノードID |
| `parent_id` | 親ノードID |
| `order` | 並び順 |
| `path` | 階層パス |
| `title` | タイトル |
| `summary` | 概要 |
| `content` | 本文 |
| `tags` | `\|` 区切りのタグ |
| `relations` | `\|` 区切りの関連情報 |
| `updated_at` | ISO 8601形式の更新日時 |

CSVはExcelなどで文字化けしにくいUTF-8 BOM付きです。本文中の改行、カンマ、引用符も引用処理によって保持されます。

### Markdown

ドキュメント全体を1つのMarkdownファイルとして出力します。

- ドキュメント名を第1レベルの見出しとして出力
- ツリー階層をMarkdownの見出しレベルへ変換
- 概要を引用文として出力
- タグ、本文、関連ノードを出力
- 深い階層は第6レベルの見出しで維持

ファイル名にはドキュメント名が使用され、拡張子は `.md` になります。Markdownは閲覧・共有用の出力であり、Arborへの再インポートには対応していません。

### JSON Schema

「JSON Schema」を選択すると、次のファイルをダウンロードできます。

```text
arbor-document.schema.json
```

JSON Schema Draft 2020-12準拠で、ドキュメント、ノード、タグ、関連性、必須フィールド、データ型などを定義しています。

## データの読み込み

右上の「読み込む」から、Arborが出力したJSONまたはCSVを読み込めます。

読み込み方法：

- 現在のドキュメントを置き換える
- 現在のツリーに追加する

追加モードではIDを再生成し、既存データとの衝突を防止します。JSONからはタグや関連性を含む構造を復元し、CSVからも階層、タグ、関連ノード、複数行の本文を復元します。

AI接続設定とAPIキーは、インポートおよびエクスポートの対象外です。

## データ保存

以下の情報はブラウザのIndexedDBに保存されます。

- ドキュメント情報
- ノード
- タグ
- 関連性
- OpenRouter／LiteLLM接続設定
- APIキー

サーバー側のデータベースは使用しません。ブラウザやオリジンが変わるとIndexedDBも別扱いになるため、別環境へ移動する前にJSONを書き出してください。

APIリクエストはブラウザから選択したAIサービスへ直接送信されます。

## ヘルプ

右上の「？」ボタンから、アプリ内ヘルプを開けます。

ヘルプには以下を掲載しています。

- ノードの作成・編集・移動・削除
- 検索、タグ、関連ノード
- AI共同編集
- データの入出力
- キーボード操作

ヘルプやその他のダイアログは、閉じるボタン、背景クリック、または `Esc` キーで閉じられます。

## キーボード操作

| 操作 | 動作 |
| --- | --- |
| `Ctrl / Command + K` | 検索欄へ移動 |
| `Enter` | AIへの依頼を送信 |
| `Shift + Enter` | AI入力欄で改行 |
| `Esc` | 検索をクリアし、ダイアログを閉じる |

## ファイル構成

```text
.
├── index.html
└── README.md
```

HTML、CSS、JavaScript、SVGアイコンはすべて`index.html`に含まれています。

## 現在の制限

- タッチ端末ではブラウザによってドラッグ＆ドロップの操作性が異なる場合があります。
- IndexedDBのデータはブラウザとオリジン単位で管理されます。
- LiteLLMを利用する場合、サーバー側でCORSを許可する必要があります。
- APIキーはブラウザ内に保存されるため、共有端末での利用には注意してください。
- AIの出力は必ず確認してから適用してください。

## 技術仕様

- HTML5
- CSS3
- Vanilla JavaScript
- IndexedDB
- Fetch API
- OpenAI互換Chat Completions API
- JSON Schema Draft 2020-12

ビルドツール、フレームワーク、外部JavaScriptライブラリは使用していません。
